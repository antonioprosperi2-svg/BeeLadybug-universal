# Security Policy

## Supported versions

Only the latest published version of BeeLadybug is supported. Please update to the latest version before reporting a problem.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Contact the maintainer privately through GitHub: [antonioprosperi2-svg](https://github.com/antonioprosperi2-svg). Send a short message asking for a private channel, and share the details there.

Helpful details to include:

- what the problem is and where it happens
- the steps to reproduce it
- the BeeLadybug version and your browser or runtime

You will get an answer as soon as possible. Once the issue is fixed, we will publish a new version and credit you if you wish.

Thank you for helping keep BeeLadybug and its users safe.
